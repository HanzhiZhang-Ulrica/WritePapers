# 论文写作阶段导航

先读取 [README](../../README.md)，根据用户当前任务、最新材料与阶段完成标准判断入口。
用户不需要知道阶段编号；进展信息不完整时，先从当前稿件、仓库、结果与批注中确定。

所有阶段遵守 [共同要求](references/common-rules.md)。
按 README 选择对应 skill 和当前阶段的规则，不一次加载全部阶段。

阶段完成后更新进展、待核对事项及下一步。全流程任务继续推进；局部任务保留未受影响的已确认内容。

| 工作 | Skill |
| --- | --- |
| 当前版本、会议、方法事实、结果、最近邻、研究主线与证据 | [paper-research](../paper-research/SKILL.md) |
| 全文规划、图表职责、起草、各节精写与 Appendix | [paper-draft](../paper-draft/SKILL.md) |
| 六轮审阅、逐句修改、缩短、批注与排版锁定 | [paper-revise](../paper-revise/SKILL.md) |
| 终稿审计、冻结、投稿准备、审稿回应与时间安排 | [paper-audit](../paper-audit/SKILL.md) |

原始材料、PDF 与逐项来源见 [规则来源](references/source-map.md)。
